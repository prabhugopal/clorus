## What Was Implemented

### 1. `macroexpand` - Recursive Expansion
**Feature:** Recursively expand all macros in an expression and return the result as quoted data.

```clojure
(macroexpand '(when true (+ 1 2) (+ 3 4)))
; => (if true (do (+ 1 2) (+ 3 4)) nil)

(macroexpand '(-> 5 inc dec))
; => (dec (inc 5))
```

**Implementation:**
- Added handling in codegen.rs to intercept "macroexpand" function calls
- Calls `macros::expand_macros()` from clorus-syntax
- Returns result using `compile_quoted()` to convert AST to runtime data

### 2. `macroexpand-1` - Single-Step Expansion
**Feature:** Expand only the outermost macro (single step), useful for debugging nested macro expansions.

```clojure
(macroexpand-1 '(when true (+ 1 2)))
; => (if true (do (+ 1 2)) nil)

;; Note: inner expressions are NOT expanded
(macroexpand-1 '(cond (< x 0) "neg" :else "pos"))
; => (if (< x 0) "neg" "pos")
```

**Implementation:**
- Added `expand_macros_once()` public function to macros.rs
- Added `expand_macros_once_with_registry()` internal helper
- Added `apply_user_macro()` for user-defined macro expansion without recursion
- Added helper functions for each builtin macro (expand_thread_first_once, etc.)

### 3. Extended `compile_quoted` to Support Expanded Forms
**Feature:** Extended `compile_quoted()` to handle `Expr::If`, `Expr::Call`, and `Expr::Do` which are generated by macro expansion.

**Implementation:**
- Added case for `Expr::If` - converts to vector: `["if" condition then else]`
- Added case for `Expr::Call` - converts to vector: `[func arg1 arg2 ...]`
- Added case for `Expr::Do` - converts to vector: `["do" expr1 expr2 ...]`
- Uses LLVM vector construction with conj for building quoted forms at compile time

## Implementation Details

### Single-Step Expansion Strategy
1. Created `expand_macros_once` that expands only the outermost macro
2. Does NOT recursively expand the result
3. Each builtin macro has an `expand_X_once` helper that doesn't recurse
4. User-defined macros use `apply_user_macro` which doesn't expand arguments

### Quoted Form Generation
1. Expanded AST is converted back to runtime data structures
2. Uses LLVM vector construction with `clorus_vector_conj`
3. Symbols are represented as strings (no Symbol runtime type yet)
4. Preserves structure: `(if cond then else)` becomes `["if" cond then else]`

### Module Organization
- **macros.rs**: Pure AST transformation functions
- **codegen.rs**: LLVM IR generation for quoted forms
- No runtime changes needed (uses existing vector/string functions)

## Use Cases

### Debugging Macros
```clojure
;; See what a macro expands to
(macroexpand '(when (> x 10)
                (println "big")
                (inc x)))

;; Step through expansion one level at a time
(def expr '(when (> x 10) (inc x)))
(def step1 (macroexpand-1 expr))   ; => (if (> x 10) (do (inc x)) nil)
(def step2 (macroexpand step1))     ; => fully expanded
```

### Understanding Macro Behavior
```clojure
;; Compare single-step vs full expansion
(macroexpand-1 '(-> x (f a) (g b)))  ; => (g (f x a) b)
(macroexpand   '(-> x (f a) (g b)))  ; => (g (f x a) b) [same]

;; But with nested macros:
(macroexpand-1 '(when (and a b) body))  ; => (if (and a b) (do body) nil)
(macroexpand   '(when (and a b) body))  ; => (if (if a b false) (do body) nil)
```

### Writing Better Macros
```clojure
;; Check if your macro expands correctly
(defmacro unless [test then else]
  `(if ~test ~else ~then))

(macroexpand '(unless false 1 2))  ; => (if false 2 1)
```

## Performance Notes

- **macroexpand**: O(n) where n is total macro forms (recursively)
- **macroexpand-1**: O(1) single-step expansion only
- **compile_quoted**: O(n) LLVM IR generation for n elements
- **Zero runtime overhead**: Expansion happens at compile time
- **Returns data**: Result is runtime vector/string, not compiled code

---

## Known Limitations

1. **Symbol Representation**: Symbols are represented as strings in quoted output (no Symbol runtime type)
2. **Vector Output**: Expanded forms are returned as vectors, not as true lists (Clorus doesn't have List literals yet)
3. **Function Names as Strings**: Function names in calls become string values, not symbol values

## Examples

### Basic Usage
```clojure
;; Expand a when macro
(macroexpand '(when true 1 2))
; => ["if" true ["do" 1 2] nil]

;; Single-step expansion
(macroexpand-1 '(cond (< x 0) "neg" :else "pos"))
; => ["if" ["<" "x" 0] "neg" "pos"]
```

### Complex Macros
```clojure
;; Threading macros
(macroexpand '(-> x (f a) (g b) (h c)))
; => ["h" ["g" ["f" "x" "a"] "b"] "c"]

(macroexpand '(->> x (map inc) (filter even?)))
; => ["filter" "even?" ["map" "inc" "x"]]
```

### Conditional Macros
```clojure
;; cond expansion
(macroexpand '(cond
                (< x 0) "negative"
                (= x 0) "zero"
                :else "positive"))
; => ["if" ["<" "x" 0] "negative"
;      ["if" ["=" "x" 0] "zero" "positive"]]
```
