# Clorus Documentation

This repo now uses a canonical-doc model with **one human source of truth** and
**one machine source of truth** for status:

- Human canonical status: [generated/PARITY_STATUS.md](generated/PARITY_STATUS.md)
- Machine canonical status: [generated/STATUS.json](generated/STATUS.json)

Everything else is either:

- a derived view from those generated files, or
- narrative/reference documentation.

Top-level reference docs:

- [Language](LANGUAGE.md)
- [Compiler & Architecture](COMPILER_ARCHITECTURE.md)
- [Rust Interop](RUST_INTEROP.md)
- [Production Plan](PRODUCTION_PLAN.md)
- [Generated Coverage Summary](generated/COVERAGE_SUMMARY.md) — derived view

Stable pointer docs remain for backward compatibility:

- [Parity Checklist](PARITY_CHECKLIST.md)
- [Coverage](COVERAGE.md)
- [Language Parity](LANGUAGE_PARITY.md)

## Progress Report

[site/progress.html](site/progress.html) is a source-verified status/progress report (jank-progress-style dashboard covering execution model, Rust interop, language feature parity, stdlib coverage, test health, and the production roadmap). It's a manually-audited snapshot, not generated by `build_status.py` — open it directly in a browser. Dated 2026-07-30; refresh by re-auditing against source (not against other docs) as the roadmap below progresses.

## Archived/Deep Docs

Detailed historical, design, and session docs remain in subfolders (`archive/`, `design/`, `guides/`, `sessions/`, etc.) and are useful context, but are not the top-level canonical entrypoints.

python3 scripts/docs/build_status.py
